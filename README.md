# ORVANA Integrated Systems — Website

Stack: Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · lucide-react · Outfit font.

## Run locally
npm install
npm run dev

## Deploy to Vercel
Push this folder to GitHub, then import the repo at vercel.com/new (framework auto-detected as Next.js). No environment variables are needed.
